위성 변위 분석 기준(요약)
지점별 경보/라벨 산정의 핵심 규칙과 지표 정의
RULE
ACCEL (가속 징후)
  • R1 = ratio4 ≥ R1_RATIO4_THR
  • R2 = |s_last4| ≥ R2_ABS_S_LAST4_THR
  • R3 = |net8| ≥ R3_ABS_NET8_THR
  • ACCEL = R1 ∧ R2 ∧ R3 (권장: p95 기반)
CREEP (지속 변형)
  • C1 = |s_last4| ≥ R4_ABS_S_LAST4_THR
  • C2 = |net8| ≥ R4_ABS_NET8_THR
  • C3 = s_last4/net8 동일 방향
  • CREEP = C1 ∧ C2 ∧ C3 (권장: p90 기반)
IF (Isolation Forest)
IF 임계치: if_score ≤ -0.574036 (p7)
FEATURES
  • cum_mm: 누적 변위(mm) — 총 변위량
  • s_prev4, s_last4(mm/yr): 이전/최근 4점 구간 속도
  • ratio4 = |s_last4| / |s_prev4|: 가속(추세 변화) 지표
  • net8 = cum(t)-cum(t-7): 최근 8관측 누적 변화량
LABEL
  • RED = ACCEL ∧ IF
  • WATCH_A = ACCEL ∧ ¬IF
  • WATCH_B = CREEP ∧ ¬ACCEL
  • WATCH_C = ¬ACCEL ∧ ¬CREEP ∧ IF
  • 우선순위: RED > WATCH_A > WATCH_B > WATCH_C > NONE
TIP: 지점을 클릭하면 상세 페이지에서 시계열(cum_mm)과 상세 컬럼(s_last4/net8/ratio4/IF 등)을 확인할 수 있습니다.
