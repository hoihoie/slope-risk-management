임계치 · 규칙 · 라벨 기준

규칙(Threshold)

아래 규칙은 CSV의 R1~R3/ACCEL, C1~C3/CREEP, IF 컬럼에 반영되는 판정 로직입니다.

RULE ACCEL (가속 징후)
  • R1 = ratio4 ≥ R1_RATIO4_THR
  • R2 = |s_last4| ≥ R2_ABS_S_LAST4_THR
  • R3 = |net8| ≥ R3_ABS_NET8_THR
  • ACCEL = R1 ∧ R2 ∧ R3

운영 임계치(권장): ACCEL 관련 임계값은 상위 95 분위수(p95) 기반.

RULE CREEP (지속 변형)
  • C1 = |s_last4| ≥ R4_ABS_S_LAST4_THR
  • C2 = |net8| ≥ R4_ABS_NET8_THR
  • C3 = s_last4와 net8가 동일 방향(부호 동일)
  • CREEP = C1 ∧ C2 ∧ C3

운영 임계치(권장): CREEP 관련 임계값은 상위 90 분위수(p90) 기반.

MODEL IF (Isolation Forest)
  • IF 임계치 = if_score ≤ -0.574036 (하위 7 분위수, p7)

지표 해석 · 라벨 정의

지표(Features)

  • cum_mm: 해당 날짜의 누적 변위(mm) — 얼마나 움직였나(총량)
  • s_prev4, s_last4 (mm/yr): 최근 8개 관측을 4+4로 분할한 구간별 속도(이전/최근)
  • ratio4 = |s_last4| / |s_prev4| — 가속 지표(추세 변화/가속 가능성)
  • net8 = cum(t) - cum(t-7) — 최근 8개 관측 동안의 실제 누적 변화량

라벨(Label)

  • RED = ACCEL ∧ IF
  • WATCH_A = ACCEL ∧ ¬IF (CREEP 여부 무관)
  • WATCH_B = CREEP ∧ ¬ACCEL (IF 여부 무관)
  • WATCH_C = ¬ACCEL ∧ ¬CREEP ∧ IF
  • NONE = 그 외

라벨 우선순위: RED > WATCH_A > WATCH_B > WATCH_C > NONE

임계값 설계 원칙(요약)

  • 운영 가능한 알림량(FP 통제)과 이벤트 전 선행 탐지(lead time)의 균형을 목표
  • 정답 라벨이 부족해 Xinmo 주변 Negative 샘플로 정상 분포를 근사 → 분위수 기반 자동 튜닝
  • FP_ANY_NONNONE: 정상 구간에서 RED/WATCH_* 중 하나라도 뜨는 전체 비율(= 운영자가 확인해야 하는 전체 알림 부담)
  • WATCH_A(ACCEL): p95(보수적·신뢰도 우선) — Xinmo 기준 12일 리드타임, FP_RED 1.6%, FP_ANY_NONNONE 4.5%
  • WATCH_B(CREEP): p90(조기 탐지) — Xinmo 기준 24일 리드타임, FP_WATCH_B 0.24%, FP_ANY_NONNONE 5.4%
